# GreenRoom Roadmap

## Live today

- User-triggered watches for AI-video tools, selected YouTube platform changes, and selected Twitch creator opportunities.
- Persistent creator Memory and relevant-context selection.
- One verified persistent Mind producing creator-specific attention verdicts.
- Asynchronous objective-bound runs, provenance, history, and feedback.

## Next

- Measure and improve Minds reply reliability, latency, deadlines, and observability.
- Validate the target user and highest-cost monitoring jobs with independent creators.
- Improve Memory inspection/correction and golden-path usability from observed behavior.

## Later, contingent on evidence

- Add source coverage selected from real creator workflows.
- Add creator-owned account/data connectors where they materially improve verdicts.
- Add recurring watches and notifications after reliability and notification-value testing.
- Test paid packaging only after credible demand evidence.

Everything below **Live today** is planned, not implemented.
