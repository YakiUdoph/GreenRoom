# GreenRoom Roadmap

All items below are plans unless explicitly described as present in the stable repository.

## Now — Hackathon

Present foundation:

- Persistent creator profile and decision Memory.
- Creator objectives and immutable run snapshots.
- Real Udophia integration through Minds Builder.
- QStash background orchestration and durable persistence support.
- Decision briefing contract.
- Run isolation and honest simulated-evidence provenance.

Hackathon priority: present this foundation truthfully and demonstrate failure-safe behavior without adding surface area.

## 0–30 days

- Harden Minds execution reliability, deadlines, recovery, and observability.
- Establish reply-success and latency baselines.
- Recruit a 10–20 creator beta cohort.
- Conduct creator interviews before asserting problem validation.
- Integrate the first real external creator-data source.
- Instrument objective creation, briefing completion, action, rejection, and repeat use.

## 30–60 days

- Add recurring creator objectives.
- Expand real creator signals with explicit source provenance.
- Improve feedback-driven relevance and memory retrieval.
- Add useful completion/failure notifications.
- Explore creator workflow integrations based on interview evidence.

## 60–90 days

- Test a paid Pro beta.
- Support multiple concurrent creator objectives without weakening run isolation.
- Provide richer, creator-readable decision history.
- Explore manager and agency workflows.
- Evaluate ecosystem distribution opportunities.

## Longer term

- Establish GreenRoom as creator intelligence infrastructure.
- Integrate across creator platforms while retaining evidence integrity.
- Explore team and studio versions.
- Use Minds ecosystem capabilities and distribution where they create measurable creator value.
